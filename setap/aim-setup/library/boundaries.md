# boundaries · контуры и границы данных

Агент читает этот файл, когда человек работает с данными работодателя или клиентов, или спрашивает, как разделить рабочее и личное.

## что сказать человеку прямо

Всё, что агент прочитал, уходит провайдеру модели. Настройки набора запрещают читать `.env` и ключи, но надёжно закрыть файл можно одним способом: не класть его туда, куда агент ходит. Условия хранения и обучения зависят от тарифа и меняются: человек сверяет их в настройках своей подписки. Точных обещаний о них не давай.

Работодатель запрещает отдавать код или данные внешним моделям – этот запрет сильнее набора. Обходы не предлагай. Рабочие варианты: корпоративная подписка, которую разрешила компания; проект на вымышленных данных той же формы; своё дело, которое не касается работы.

## файл `context/boundaries.md`

```markdown
# Границы

- **Контур этой папки:** <личный / рабочий / клиент такой-то>
- **Можно читать:** <папки и виды файлов>
- **Только по просьбе в этой сессии:** <что человек назвал>
- **Нельзя читать и класть сюда:** <данные клиентов, код работодателя, медицинское, переписка>
- **Что разрешает работодатель:** <сказано человеком / «не знает» / «не про работу»>
```

Правило для агента: в начале сессии читай этот файл. Нужен файл из строки «нельзя» – не открывай его, скажи человеку, чего не хватает, и предложи заглушку той же формы. Новая граница прозвучала в разговоре – допиши строку и покажи её.

## уровни доступа

Уровни – из сетапа лабы AI Mindset, по материалам Саши Поваляева. У файла можно поставить поле `access:` в шапке; без поля файл считается T1.

| уровень | что | что делает агент |
|---|---|---|
| T0 публичное | уже открыто миру | читает и цитирует |
| T1 рабочее | кто я, чем занят, как работаю, проекты | читает на старте |
| T2 адресное | выбранное для конкретного человека | показывает только адресату |
| T3 личное (`private: true`) | дневник, отношения, личные деньги | не читает без просьбы в этой сессии |
| T4 уязвимое | здоровье, терапия, данные других людей | файла в папке нет, только указатель |

Повышать уровень можно без вопроса, понижать – только человек.

## рецепт двух папок

Работа и личное – две отдельные копии набора:

```
~/aim-personal/   набор, свой context/, своё project
~/aim-work/       набор, свой context/, своё project
```

- Каждая копия открывается в агенте отдельно. Свои `context/`, правила и история сессий не смешиваются.
- Копии лежат рядом. Вложить одну в другую нельзя: Claude Code читает `CLAUDE.md` из папок выше, и правила смешаются.
- Аккаунт один на компьютер, папка его не меняет. Перед рабочей сессией проверь, под каким ты вошёл: `/status` в Claude Code, `codex login status` в Codex; сменить – `/login` и `codex login`.
- Правила из опыта переносит человек руками, строкой в `context/lessons.md` другой копии. Детали клиентов в такие строки не идут.
- Ключи у каждой копии свои.
